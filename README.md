# Pokeye Portfolio

An accessible, static developer portfolio built from the selected **Developer's Laboratory** cyberpunk direction.

## Current state

The application shell, visual system, responsive layout, dark/light theme toggle, keyboard-accessible mobile navigation, and original local schematic illustrations are implemented. Project and contact details are intentionally starter content because the workspace did not include verified project records, URLs, or contact information.

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run build
npm run test:sites
```
