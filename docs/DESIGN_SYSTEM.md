# Design system

## Tokens

Dark: `#101014` background, `#17171D` surface, `#F2F0F2` text, `#A5A1AA` muted text, `#48434D` rule, `#F02D8A` accent, and `#A9F5E8` technical highlight.

Light: `#F0EFEA` background, `#FAF9F5` surface, `#17171A` text, `#5F5D63` muted text, `#B6B3B0` rule, `#D51E72` accent, and `#176B65` technical highlight.

## Typography and layout

- Display: Barlow Condensed, used only for headings and labels with strong hierarchy.
- Body: Manrope, used at readable body sizes.
- Technical copy: IBM Plex Mono, used for indexes and metadata.
- Page gutters scale from 20px on small screens to 4.6vw on wide displays.
- Borders are 1px and shadows are intentionally absent.

## Motion and interaction

Theme indicator transitions are short; `prefers-reduced-motion` removes transitions and smooth scrolling. All actionable elements show a visible mint focus outline.
