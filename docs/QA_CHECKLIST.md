# QA checklist

## Implemented checks

- [ ] Build and Sites worker tests.
- [ ] Desktop, tablet, and mobile rendering.
- [ ] Theme persistence after reload.
- [ ] Keyboard navigation, focus visibility, and mobile menu behavior.
- [ ] Reduced-motion behavior.
- [ ] Verified contact and project destinations once real content is supplied.
- [ ] Contrast review in both themes.

## Content checks before publishing

- [ ] No unverified project claims or metrics.
- [ ] No starter email remains.
- [ ] Every project status is supported by evidence.
- [ ] Decorative images remain local and labelled correctly.
