# Portfolio redesign specification

## Audit

At implementation start, the supplied workspace contained only the source master brief. No pre-existing application, packages, routes, project evidence, contact links, or visual reference image were available. A new Vite/React static prototype was therefore created in `pokeye-portfolio/`.

## Chosen direction

The selected visual target is the first generated direction: an asymmetric technical editorial landing page, led by a large identity statement and a right-hand original laboratory wireframe. Thin rules, monospace microcopy, restrained magenta accents, and dark technical surfaces express the Developer's Laboratory identity.

## Implemented scope

- One responsive portfolio landing page with Home, Projects, Approach, and Contact landmarks.
- A persistent light/dark theme preference.
- Keyboard-accessible collapsed mobile navigation.
- A clearly labelled starter project record, rather than fabricated portfolio claims.
- Original local raster illustrations for the hero and featured-project composition.

## Deliberate limitations

Real projects, social URLs, a resume, contact email, and project status are not yet known. The UI calls these out as starter content and does not present them as live evidence.

## Future work

Replace starter content with verified records; add case-study routes only when there is enough real content to justify them.
